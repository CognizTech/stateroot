# StateRoot

**Version control for AI-assisted work.**
**Switch agents. Nothing is lost.**
**Local-first. No account required.**

StateRoot lets you move between Claude Code, Codex, Cursor, Kimi and other coding agents without losing the state of your work. Your project stays on your machine — StateRoot tracks how agents change it, preserves the context they leave behind, and carries shared memories, skills and learnings between them.

```text
Claude Code ──→ State A ──→ State B
                             │
                             ├── continue with Codex
                             ├── branch with Cursor
                             └── restore an earlier state
```

## Install

```bash
# Linux / macOS
curl -sSfL https://github.com/CognizTech/stateroot/releases/latest/download/install.sh | sh

# Windows (PowerShell)
irm https://github.com/CognizTech/stateroot/releases/latest/download/install.ps1 | iex
```

One binary. No account. No server. Updates arrive on their own.

## Quickstart

```bash
cd my-project
stateroot init
```

Then keep working in your usual agent. When you switch tools — or hit a usage limit mid-task — the next agent picks up where the last one left off:

```bash
stateroot status     # where the project stands
stateroot log        # the state history
stateroot resume     # the full continuation brief for the next agent
```

## What you get

| | |
|---|---|
| **Project state history** | Track project states created by agent work and inspect what changed. |
| **Cross-agent continuity** | Continue in another agent without rebuilding context by hand. |
| **Branches & restore** | Fork from earlier states, compare alternatives, restore previous work. |
| **Shared intelligence** | Carry memories, skills, learnings and working preferences across harnesses. |
| **Local-first** | Everything runs on your machine. No account, no hosted server required. |
| **Git-friendly** | Works alongside your existing Git workflow, not in place of it. |

### Trust what you're restoring

StateRoot distinguishes mechanically verified project changes from information observed from agent sessions and content generated by AI — and keeps the provenance attached, so you can see where anything came from.

## Supported harnesses

Claude Code · Codex · Cursor · Kimi Code · OpenClaw · Hermes — with more on the way.

## Privacy

Your project never leaves your machine. Files matched by `.gitignore` or `.staterootignore` are excluded from state tracking, and `.stateroot/local/` is never shared.
